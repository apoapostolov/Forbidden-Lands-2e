## Purpose

This is the unified manual for the `forbidden-lands-writing` skill.

It consolidates the writing references into one research-grade source document so the AI can draft or revise manuscript-facing prose without falling back on generic fantasy or generic instructional writing.

## Voice Identity

The manuscript voice is:

- harsh
- clear
- grounded
- practical
- myth-shadowed but not vague
- atmospheric without ornament for ornament’s sake

It is not:

- generic fantasy imitation
- modern game-tech prose
- clinical explanatory copy
- proposal-rationale language

## Register System

The manuscript uses several related registers, not separate voices.

### Fiction opener

- brief
- vivid
- body or object anchored
- closes on an image

### Flavor exposition

- names the condition of the world
- turns quickly toward what it means for adventurers

### Rules exposition

- defines
- explains
- limits

### Mixed flavor-and-rule bridge

- opens materially
- pivots to operation

### Item description

- concrete noun first
- distinction through use

### Example scene

- names actors
- shows order
- teaches through consequence

## Corpus Use

Retrieve by job, not only by topic.

Use:

- `03-skills.md`, `05-combat-and-damage.md`, `08-journeys.md` for rules procedure
- `10-gear.md` for item and tool prose
- `06-critical-injuries.md` for consequence honesty
- `01-front-matter.md` and `02-your-adventurer.md` for atmospheric framing

Default retrieval size:

- two to five targeted passages

## Paragraph And Sentence Rules

Measured prose averages across the corebook show that the manuscript generally prefers:

- short-to-medium paragraphs
- roughly 35 to 60 words in many practical chapters
- roughly 2 to 4 sentences in the common case

Default paragraph logic:

- one paragraph, one job

Default sentence logic:

- short for force
- medium for explanation
- long only when carrying controlled scene detail

Preferred endings:

- hard nouns
- bodily terms
- material consequences

## Diction Rules

Prefer:

- blood
- iron
- stone
- grip
- hand
- cold
- frost
- trail
- ash
- burden
- hunger

Prefer concrete verbs:

- cut
- drag
- haul
- bind
- split
- break
- climb
- carry

Avoid:

- abstract filler
- modern blog phrasing
- therapy language
- inflated epic diction

## Structural Rules

Use the manuscript’s dominant paragraph shapes:

### Statement -> consequence

For:

- items
- subsystem intros
- practical world rules

### Definition -> procedure -> exception

For:

- core rules
- timing
- recovery
- action logic

### Condition -> pressure -> response

For:

- journeys
- weather
- scarcity

### Description -> distinction

For:

- weapons
- materials
- profession and kin contrasts

Also yield to structure when scanning matters:

- lists
- bold labels
- tables
- headings

Do not force dense comparison through prose alone.

## Example Rules

Use examples when:

- rules interact
- timing matters
- a likely misreading exists

Structure:

1. scene
2. trigger
3. roll
4. result
5. consequence

Examples should feel like moments in play, not sterile demonstrations.

## Anti-Style Warnings

Watch for:

- AI-generic fantasy fog
- modern tutorial filler
- clinical naming drift
- proposal rationale leakage
- overdecorated epic prose

The fix is usually the same:

- make the noun concrete
- make the verb physical
- cut one adjective
- restore the paragraph’s actual job

## Revision Method

When revising:

1. identify the register
2. retrieve local exemplars
3. check paragraph job
4. sharpen nouns and verbs
5. remove modern drift
6. verify rule clarity
7. add or cut examples only when justified

Use this rubric:

- voice fidelity
- structural fit
- clarity
- terminology integrity
- example necessity
- table usability

## Practical Use

When the skill needs concrete examples rather than abstract guidance, load:

- `rewrite-calibration-examples.md`
- `multi-rule-sequence-calibration.md`

Use that file to calibrate revision choices against real repo transformations before drafting new manuscript prose.

When asked to write or revise manuscript text:

1. identify text type
2. retrieve the right exemplars
3. draft with one paragraph job at a time
4. prefer concrete diction
5. end sentences on weight
6. remove proposal or blog drift

The governing rule is simple:

Write as if the text always belonged in this book, and make the prose carry both atmosphere and use without letting either swallow the other.
