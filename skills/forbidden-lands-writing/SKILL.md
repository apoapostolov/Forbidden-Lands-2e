# Forbidden Lands Writing

Use this skill for any prose that should read like native manuscript text in the Forbidden Lands 2E repo.

## Source Of Truth

Read these files before drafting:

- `AGENTS.md`
- `WRITING_GUIDE.md`

When working in chapter or proposal folders, also read the local `AGENTS.md` there if present.

## What This Skill Is For

Use it when you need to:

- draft or revise `corebook/` prose
- rewrite a proposal so it sounds manuscript-native
- tighten rules explanations without losing flavor
- write examples that teach several small rules in one playable scene
- review text for tone drift, modern diction, or weak paragraph structure

Do not use it for purely mechanical analysis with no prose drafting. Use the design or balance skill instead.

## Writing Workflow

1. Identify the text type.
   - Rules text
   - Flavor explanation
   - Mixed flavor-and-rule bridge
   - Example scene
   - Proposal prose intended for later promotion
2. Pull local exemplars from the relevant chapter before drafting.
3. Draft to the sentence and paragraph patterns described in `WRITING_GUIDE.md`.
4. Keep rules text precise and brief. Keep flavor text concrete and material.
5. If the text is going into `corebook/`, remove proposal rationale and editorial scaffolding.
6. Self-check the result against the checklist below before finalizing.

## House Style Rules

- Prefer hard nouns and plain verbs over abstract modern phrasing.
- Keep the prose severe, grounded, and useful at the table.
- Explain only what the reader needs to act on the rule.
- Use examples only when several small rules interact or a timing sequence would otherwise be unclear.
- Let paragraph size match function. Do not turn every rule into a wall of text.
- Avoid therapeutic, corporate, academic, or clinical language unless the manuscript already uses it.
- Avoid generic fantasy padding.

## Example Policy

Add an example when:

- multiple small rules interact in one sequence
- timing or order of operations matters
- the rule is easy to misread in play

Keep examples short, concrete, and game-active. Name who acts, what is rolled, what changes, and why it matters.

## Review Checklist

Before finalizing, verify:

- the wording fits the manuscript voice
- paragraph shape matches the job of the section
- sentence lengths vary with purpose rather than by accident
- rule hooks use existing game terms where possible
- no modern or AI-generic phrasing slipped in
- examples exist only where they earn their space

## Output Expectations

When asked to explain your revision, report:

- what changed in voice
- what changed in structure
- what changed in rules clarity
- any remaining integration or terminology risks
