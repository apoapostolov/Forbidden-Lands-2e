# Layout Analysis

Use this when a PDF is unfamiliar, badly damaged, or full of repeated layout patterns.

## What to survey

1. TOC and chapter breaks
2. page count and spread count
3. sample geometry from opening, middle, and late pages
4. repeated headers, footers, page furniture, and title treatments
5. fonts and style markers
6. image inventory, including repeated icons and full-page art
7. table inventory, especially matrix tables, statblocks, and roll tables

## What to record

- single-column or multi-column layout
- repeated page-band text
- heading styles and title treatment
- repeated images or icons
- tables that must stay structured

## Output shape

A good survey ends with:

- a chapter map
- a page-geometry summary
- a font summary
- an image summary
- a table summary
- a profile choice

Use the survey to decide where structure repair matters most.
