# Visual Comparison

Use the PDF as the tie-breaker whenever layout and text extraction disagree.

## When to compare visually

- two columns interleave prose and data
- a table is embedded in prose
- a sidebar has been mistaken for body text
- a heading fragment might actually belong to the previous page

## Fast comparison flow

1. identify the suspicious span in the markdown
2. open the corresponding PDF page or spread
3. inspect the same text in reading order
4. decide whether the extracted order is wrong or merely ugly
5. replace the damaged span in one operation when the ownership is clear

## Useful search pattern

If you know the page number, jump to the source page and search for the exact excerpt first. If you only know a phrase, search the PDF for the phrase and inspect the surrounding spread.

## Rule

Use visual comparison to confirm structure, not to justify guessing.
