# Layout Analysis Workflow

Use this when a PDF is unfamiliar, badly damaged, or full of repeated layout patterns that the first extraction pass did not explain.

## What To Survey

Start with a quick structural pass before any prose cleanup:

1. TOC/bookmarks and chapter breaks
2. page count and spread count
3. sample page geometry from the opening, middle, and late sections
4. repeated running headers, footers, page furniture, and title treatments
5. font families, sizes, and bold/italic patterns
6. image inventory, including repeated icons, banners, and full-page art
7. table inventory, especially matrix tables, statblocks, and roll tables

## What To Record

Keep a short note of:

- whether the document is mostly single-column prose or two-column rules text
- which blocks repeat in the page margin bands
- which fonts appear to mark headings, labels, captions, or body text
- which images repeat across pages
- which tables need reconstruction before prose repair can be trusted

## How To Interpret It

- Consistent left and right text blocks usually indicate a two-column spread.
- Repeated near-margin text is usually running furniture, not body copy.
- Large images with high dimensions are usually chapter art or illustrations.
- Small repeated images are usually icons, bullets, dividers, or decoration.
- Tables with stable row structure should be repaired as tables, not flattened into paragraphs.
- Font shifts often mark headings, boxed notes, labels, or caption text.

## Output Shape

A good survey leaves you with:

- a chapter map
- a page-geometry summary
- a font summary
- an image summary
- a table summary
- a profile choice for the main cleanup pass

## Why It Matters

Layout evidence tells you where to spend attention. It prevents the two common failures:

- over-editing into invented prose
- under-editing by trusting a broken extractor too much

Use layout analysis to choose the least-wrong profile and the safest repair order.
