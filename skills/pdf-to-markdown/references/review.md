# Review Checklist

Use this to sanity-check the cleaned markdown.

## Check the structure

- title reads naturally
- chapter order makes sense
- section headings are at the right depth
- lists render tightly
- tables stay as tables

## Check the noise

- page numbers are gone
- running headers are gone
- footer slogans are gone
- picture placeholders are gone
- stray `<br>` tags are gone

## Check the prose

- no mid-sentence column breaks remain
- no obvious drop-cap damage remains
- no linewise hard-wrap damage remains where it should have been joined

## Check the risky blocks

- no table has been flattened into prose
- no prose block has been mistaken for a table
- no blockquote has an accidental blank line between related lines

## Final rule

If a section still looks suspicious, reopen the PDF and verify the page visually before changing more text.
