## Purpose

This reference exists because balance questions in tabletop roleplaying games are almost never solved by raw math alone.

In an RPG, a rule can be mathematically fair and still be unhealthy because:

- it feels deceptive
- it monopolizes spotlight
- it pressures the GM into constant correction
- it creates incentives the table dislikes
- it distorts the campaign over time

This framework is meant to keep those layers separate and visible.

## The Four Balance Lenses

### 1. Mathematical balance

Questions:

- how often does the rule succeed
- how much value does it produce when it succeeds
- what is the downside frequency
- what is the opportunity cost

Use this lens for:

- dice odds
- action economy
- resource conversion
- damage and mitigation
- recovery rates

### 2. Perceived balance

Questions:

- does this feel fair when seen from the player's chair
- does this feel fair when seen from the GM's chair
- does the payoff match the fantasy promised by the text

Use this lens for:

- disappointment
- envy
- resentment
- sense of bait-and-switch

### 3. Table balance

Questions:

- who gets attention because of this rule
- who waits because of this rule
- who has to remember the exceptions
- who has to adjudicate the mess when it goes wrong

Use this lens for:

- spotlight dominance
- cognitive load
- argument frequency
- rule handling time

### 4. Campaign balance

Questions:

- what happens if this is used repeatedly over ten sessions
- does it flatten core pressures
- does it scale into a dominant line
- does it obsolete other long-term choices

Use this lens for:

- progression
- attrition
- recovery loops
- wealth and equipment scaling

## Psychological Balance

Psychological balance concerns how the rule is understood and emotionally processed.

### Core principle

People do not evaluate a rule only by its true output.
They evaluate it by:

- what they expected
- how clearly they saw the risk
- whether the failure felt deserved
- whether the reward felt worth the exposure

### Key psychological hazards

#### Trap option

The option appears attractive, but informed players know it is poor or unsafe.

Consequence:

- new players feel punished for trusting the text

#### Bully option

The option is so strong or oppressive that other players or the GM must constantly adapt around it.

Consequence:

- resentment
- spotlight distortion

#### False hope option

The option promises agency or payoff, but the actual odds or practical use are too poor.

Consequence:

- repeated frustration
- a feeling that the system lies

#### GM mercy dependency

The option is only fun if the GM quietly softens or redirects its consequences.

Consequence:

- unstable table experience
- inconsistent campaign tone

## Player Expectation Models

Players usually read rules through one or more of these lenses:

### Fantasy expectation

"This lets me be the kind of character I imagined."

Risk:

- if the rule does not actually deliver that fantasy, dissatisfaction is high even if the math is fair

### Competence expectation

"If I invest here, I should be reliably better."

Risk:

- if outcomes remain too random or too conditional, the player feels cheated

### Fair-risk expectation

"If I take a serious risk, the payoff should matter."

Risk:

- if risk is real but reward is thin, players stop engaging

### Readability expectation

"I should understand what I am committing to before I choose."

Risk:

- hidden edge cases create anger rather than healthy surprise

## GM Expectation Models

GMs usually evaluate a rule through different lenses:

### Adjudication expectation

"Can I run this without constant edge-case rulings?"

If not, the rule drains attention from the fiction.

### Pressure expectation

"Does this preserve the intended level of danger, scarcity, or uncertainty?"

If not, the GM feels pushed to compensate with harsher encounters or informal nerfs.

### Ensemble expectation

"Will this let the whole group play, or does it turn scenes into one character's procedure engine?"

If not, the rule damages group rhythm.

### Tone expectation

"Does this support the campaign's promise?"

If not, even a numerically fair rule can feel wrong.

## Game Theory Checks

### Dominant strategy

If one option is almost always better, other choices become decorative.

### Degenerate loop

The rule feeds itself or combines with another rule to create a self-sustaining exploit.

### False choice

Several options appear different, but one is clearly superior in real play.

### Incentive collision

The best move for an individual player harms the party or the campaign, yet the rules reward it anyway.

### Information asymmetry failure

The best use of the rule depends on knowledge many players will not have, making the rule functionally unfair.

## Campaign-Scale Analysis

Never stop at one-scene balance.

Ask:

- what happens after repeated use
- what costs can be healed, reset, or bypassed
- what becomes routine instead of dramatic
- what previous advancement choices lose value

### Repetition test

If a rule is fair once but oppressive when repeated, it is still unbalanced.

### Resource erosion test

If the rule is balanced only because it supposedly costs resources, verify whether those resources are actually scarce over a campaign.

### Replacement test

If this rule solves too many problems, it may flatten the game's ecosystem of talents, gear, spells, or skills.

## Common False Positives

### "The numbers are fine, so the rule is fine"

False.
Perception, handling burden, and long-term incentives may still be bad.

### "It is harsh, therefore it is balanced"

False.
Harshness can still be arbitrary, misleading, or unfun.

### "It is realistic, therefore it is balanced"

False.
Realism may damage agency, pacing, and choice quality.

### "The GM can manage it"

Weak defense.
Rules that depend on expert correction are brittle.

### "It only breaks at optimization level"

Still a problem if the optimized line is obvious or attractive enough to become normal play.

## Correction Strategies

When a rule is unbalanced, the answer is not always numeric reduction.

### If the problem is math

- change cost
- change frequency
- change payoff
- add a real downside

### If the problem is perception

- rewrite the promise
- improve legibility
- make risk and reward visible before choice

### If the problem is table burden

- simplify triggers
- reduce exceptions
- move complexity to preparation instead of live play

### If the problem is campaign scale

- add friction over time
- add narrative prerequisites
- limit stacking
- preserve rival tools, talents, or procedures

## Repo-Specific Reminder

Inside the Forbidden Lands 2E repo, good balance is not "everything equal."

Good balance means:

- danger remains credible
- risk-taking remains tempting
- survival still costs something
- talents and gear keep their niches
- the GM does not need to quietly save the design from itself
