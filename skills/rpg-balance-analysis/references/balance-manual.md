## Purpose

This is the unified manual for the `rpg-balance-analysis` skill.

It consolidates the supporting references into one research-grade document that can be used when a balance question requires more than quick opinion or local arithmetic.

It is especially useful when the analysis must separate:

- what is mathematically true
- what players will feel
- what the GM must manage
- what repeated use will do to a campaign

## Balance Lenses

Use these lenses separately before combining them:

### Mathematical balance

- odds
- output
- cost
- expected value
- repeat frequency

### Perceived balance

- fairness feeling
- payoff feeling
- honesty of the promise

### Table balance

- spotlight share
- handling burden
- adjudication load

### Campaign balance

- repeated use
- attrition
- progression
- niche erosion

### Social-psychological balance

- trust
- resentment
- fear of trying things
- learned behavior

## Probability And Cost Baselines

Balance math begins with:

- success rates
- failure rates
- disaster rates
- action cost
- replenishment rate

In the Forbidden Lands case, the d6 pool baseline matters because:

- one-success tasks stabilize quickly
- multi-success thresholds remain meaningful longer
- automatic success effects are disproportionately valuable

General principle:

- a rule's action cost and replenishment model can matter more than its raw bonus

## Expectation Models

### Player expectations

Most players read rules through:

- fantasy payoff
- competence payoff
- fair-risk payoff
- legibility payoff
- dignity payoff

If a rule breaks one of these too hard, it may feel unfair even when numerically tolerable.

### GM expectations

Most GMs evaluate rules through:

- adjudication
- pressure preservation
- ensemble play
- tone support
- maintenance burden

If a rule requires hidden correction to stay fun, it is not robustly balanced.

## Spotlight And Table Burden

Spotlight is a balance resource.

Rules can distort it by granting:

- extra procedure
- extra narrative control
- constant rescue authority
- central scene relevance

Not all spotlight peaks are bad.
They become unhealthy when repeated or structurally one-sided.

## Action Economy And Game Theory

Action economy is usually a premium balance lever.

Changes to:

- number of actions
- action cost
- readiness cost
- reaction access

often matter more than small numeric buffs.

Game-theory warning categories:

- dominant strategy
- degenerate loop
- false choice
- kingmaking incentive
- anti-party incentive
- information asymmetry trap

## Harshness, Recovery, And Lethality

Harshness is not good balance by itself.

Healthy harshness:

- is legible
- improves decision quality
- feels earned

Unhealthy harshness:

- surprises
- humiliates
- stalls
- relies on GM mercy

Recovery balance is central because it defines what the game wants to remain costly.

Lethality analysis must distinguish:

- dramatic danger
- arbitrary death
- unplayable survival

These are not the same outcome.

## Narrative Authority Balance

Some rules mainly change who controls:

- truth
- memory
- emotion
- perception
- scene framing

These are balance issues even without damage or math spikes because they can:

- monopolize GM attention
- override other players' participation
- create unstable adjudication

## Synergy And Campaign Scale

Always test:

- what costs disappear when two rules combine
- what pressure channel collapses
- whether repeated use makes the combo dominant

Scene balance is insufficient.
Campaign scale is where:

- pacing collapses
- niches erode
- the GM begins counterbuilding

## Correction Methods

Use the smallest fix that addresses the real problem:

### Numeric fix

For raw output or frequency problems.

### Wording fix

For expectation mismatch or misleading promise.

### Trigger fix

For overbroad activation context.

### Cost fix

For underpriced but healthy effects.

### Scope fix

For rules doing too many jobs.

### Structural redesign

For broken incentive patterns or GM-mercy dependency.

## Forbidden Lands Applications

Forbidden Lands is a strong balance case because it is built on a harsh but legible pressure stack.

The main balance lessons from the manuscript are:

- Willpower works because risk buys power
- critical injuries work when consequence is honest
- journeys work when logistics remain meaningful
- action compression is more dangerous than it first appears
- magic stays healthy only while volatility remains meaningful
- scarcity is part of balance, not just atmosphere

This means good balance in this repo is not:

- equal comfort
- equal safety
- equal output at all times

It is:

- credible danger
- meaningful preparation
- real cost of survival
- robust niches
- minimal dependence on hidden GM repair

## Practical Use

When answering a balance question, organize analysis like this:

1. mathematical truth
2. perceived promise
3. GM management burden
4. campaign-scale effect
5. likely failure mode
6. recommended fix

When using this skill on Forbidden Lands specifically, also ask:

1. what pressure channel does the rule touch
2. does it bypass attrition, recovery, or action cost
3. does it distort the Willpower economy
4. does it create hidden non-playability

The governing principle is simple:

Balance is good when the rule is mathematically honest, psychologically legible, socially tolerable, and campaign-stable at the same time.
