# TODO: Cycle-Based Life Path Generator

This TODO breaks the proposal into ten deliberate passes.
The goal is not merely to make the system bigger.
The goal is to make it publishable:

- mechanically complete
- balanced against the rest of Chapter 2
- native to Ravenland
- clean enough to replace the current life generator without apology

Each pass should end in a document state that is reviewable on its own.
Do not rush forward while an earlier pass is still soft.

## Pass 1: Lock The Spine

**Goal:** Turn the current proposal from a strong concept into a complete system skeleton.

**Deliverables**

- [x] Finalize the core creation loop from `Kin and home` through `How did you meet?`
- [x] Decide the exact player flow for full-random, guided-random, and fully chosen use
- [x] Lock the age-to-cycle mapping for every kin
- [x] Lock the `one resolved year = one skill point` calibration rule
- [x] Define exactly how childhood foundation, cycle years, advancement, and mustering out connect without overlap
- [x] Write one clean summary page that explains the whole subsystem in one read

**Questions To Resolve**

- [x] Does the player choose age before childhood foundation or after it?
- [x] Does the final profession come from the last path only, or from a short qualification procedure?
- [x] Can a character remain in one path for all cycles, and if so, what keeps that from becoming the obvious best line?

**Done When**

- [x] A new reader can explain the whole subsystem without guessing at any missing step

- [x] Give each result two starting skill marks or one skill pair at Rank 1

## Pass 4: Build The Fallback And Path-Shift Logic

**Goal:** Make failure, exile, disgrace, and reinvention part of the engine instead of edge cases.

**Deliverables**

- [ ] Define entry gates for every path, if any
- [ ] Define forced departure triggers
- [ ] Define voluntary path change rules
- [ ] Flesh out Drifter, Laborer, and Outcast as real fallback lives
- [ ] Add rules for prison, war captivity, debt bondage, outlawry, and patron collapse where appropriate
- [ ] Build a simple path-shift table or rules block so failures create history rather than confusion

**Balance Questions**

- [ ] Does forced path change enrich the fiction without wrecking profession viability?
- [ ] Can players recover from repeated failed cycles without ending with a broken character?

**Done When**

- [ ] Failure produces compelling trajectories instead of dead ends

## Pass 5: Calibrate Numbers Against Chapter 2

**Goal:** Make sure the subsystem lands on the same rough starting power as the rest of the chapter.

**Deliverables**

- [ ] Audit attribute outcomes against the existing age rules
- [ ] Audit skill totals and skill spread for Young, Adult, and Old characters
- [ ] Audit profession access across all likely path combinations
- [ ] Audit starting gear, silver, mounts, and tools against the chapter's normal profession baselines
- [ ] Audit contacts, rumors, rivals, and scars for density and usability
- [ ] Write a balance note that states what this system is allowed to improve and what it must not inflate

**Specific Checks**

- [ ] Young characters should feel viable, not unfinished
- [ ] Adult characters should feel broad, not overpacked
- [ ] Old characters should feel seasoned, not dominant
- [ ] Casters should not bypass early-game risk
- [ ] martial builds should not begin with stacked must-have talents

**Done When**

- [ ] A generated life-path character stands beside a standard Chapter 2 character without obvious inflation

## Pass 6: Run A Full Synergy Audit

**Goal:** Stress-test the system for exploit lines before it ever reaches manuscript draft.

**Deliverables**

- [ ] Review talent-granting results against all kin and profession combinations
- [ ] Review gear outcomes for armor compression, silver inflation, and mount abuse
- [ ] Review caster routes for safe-start magic compression
- [ ] Review social and rogue routes for dominant early manipulation or stealth packages
- [ ] Review old-character cycle stacking for passive front-loaded superiority
- [ ] Build a short list of banned result types that must never appear on life-path tables

**Danger Zones To Test**

- [ ] profession talent Rank 2 starts
- [ ] multiple direct combat talents before play
- [ ] silver and gear accumulation across repeated successful cycles
- [ ] best-in-slot path chaining
- [ ] soft-optimal path choices that every informed player would take

**Done When**

- [ ] The system has no obvious one-decision dominant line

## Execution Order

Use the passes in order.
Do not collapse them into one drafting sprint.

The safe sequence is:

1. spine
2. childhood foundations
3. path coverage
4. fallback logic
5. numerical calibration
6. synergy audit
7. lore grounding
8. final prose
9. integration draft
10. publishability pass

## Working Rule

If a later pass reveals that an earlier design choice was wrong, go back and correct the earlier pass rather than layering exceptions on top.
This system should grow by sharpening, not by accretion.
