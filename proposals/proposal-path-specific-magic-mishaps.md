# Proposal - Path-Specific Magic Mishaps

Goal: replace the single generic mishap table with one mishap table per magical path, while preserving the same D66 option density as the original table. Every path should feel distinct, but no path should feel thinner than the system it replaced.

## Design Principles

- Keep the current casting engine: Willpower, overcharge, and mishap risk all stay intact.
- Keep the existing D66 modifier logic based on the number of `💀` rolled.
- Match the original mishap table's 20 result bands exactly.
- Make every result matter immediately, shortly after, or strategically.
- Tie every backlash to the actual theme of the path.
- Reserve some low-to-mid bands for item damage, local environmental spill, and same/nearby-hex stray discharge instead of repetitive self-condition results.
- Reserve `66` for the signature catastrophe of that discipline.

## Core Rule Change

When a spell causes a mishap, roll on the mishap table for the path used to cast that spell.

- A Healing spell uses the Healing mishap table.
- A Blood spell uses the Blood mishap table.
- A general spell uses the mishap table of the talent used to cast it.
- If a spell belongs to multiple themes because of custom content, use the table that best matches the spell's dominant effect.

Keep the current modifier ladder:

| Rolled `💀` | Modifier |
| --- | --- |
| 1 | `-10` |
| 2 | `+0` |
| 3-4 | `+10` |
| More | `+10` per each additional two `💀` |

## Result Bands

Each path below uses the same result bands as the original mishap table:

- `01-02`
- `03-04`
- `05-06`
- `11-13`
- `14-15`
- `16-21`
- `22-23`
- `24-25`
- `26-31`
- `32-33`
- `34-35`
- `36-41`
- `42-45`
- `46`
- `51`
- `52-55`
- `56`
- `61`
- `62-64`
- `65`
- `66`

Editorial preference for the least interesting bands:

- `14-15`: item trouble
- `16-21`: environmental change in `NEAR` or `FAR`
- `22-23`: stray discharge at a random location in the same or a nearby hex

## Shared Rule for `11-13`

Any `11-13` result is an expressive magical display, not a beneficial mishap. All unprepared non-allied witnesses must immediately roll against a `FEAR` attack with strength equal to `2 +` the Willpower spent on the spell that caused the mishap.

This display is often misunderstood. It can mark the caster as cursed, monstrous, or dangerously uncanny, but it may also scatter enemies, peasants, beasts, or other onlookers in the moment.

## Why This Works Better

- Every path now has the same 20 result bands as the original generic mishap table.
- The replacement no longer loses texture or roll variety.
- Each discipline still fails in its own idiom instead of sharing one bland mishap list.
- The catastrophic ceiling remains high, but the table has more mid-band variety again.

## Appendix A - Audit Revisions

- `11-13` no longer risks table confusion: each entry now repeats the `FEAR` cue locally, and the shared rule uses the same `unprepared non-allied witnesses` wording.
- `05-06` no longer reads like a free power-up: the extra Base Dice still surge into the next spell, but any resulting mishap roll is worse.
- The septic and blood-borne disease results at `36-41` were reduced from `everyone at ARM'S LENGTH` and Virulence `2D6` to a smaller splash and Virulence `2 +` the Willpower spent on the spell.
- Awareness and Mentalism false-information effects now state the wrong sign or assumption openly and impose bounded penalties instead of secret referee deception.
- Elemental `26-31` no longer implies an endless mishap loop or an uncastable next spell; it now increases the danger of the next Elemental casting in a bounded way.
- Several `66` catastrophe entries were tightened so they create major disasters with explicit scope, duration, or hazard limits rather than unlimited referee authority.
- A few `14-15` item-loss entries were narrowed to one meaningful item or supply bundle so the result creates trouble without casually deleting an expedition.

## Appendix B - Restored `66` Core Fate

- `66` now matches the core rule across every path mishap table: the caster is dragged through a rift by a demon, the player makes a new character, and the old one may return after `D66` days as a changed NPC.
- The former path-specific `66` results were moved to `65`.
- `65` is now reserved for path-themed catastrophic fates that are as character-ending as `66`, though in some cases the party might still attempt an extreme rescue, reversal, or containment.
